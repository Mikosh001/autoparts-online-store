# AutoParts Online Store

A five-page responsive website based on the supplied Figma design and midterm requirements.

## Pages

- `index.html` — Home
- `products.html` — Products, including the required table
- `categories.html` — Categories
- `about.html` — About Us
- `contact.html` — Contact, including the required form

## Technologies

Semantic HTML5, CSS3, and a local copy of Bootstrap 5.3.8 CSS. Layouts use Bootstrap grid and utilities, Flexbox, CSS Grid, positioning, and mobile/tablet media queries. The icons come from the supplied Figma design. There is no custom JavaScript.

## Open or publish

Open `dist/index.html` in a browser. To publish, upload the contents of `dist` to GitHub Pages or Netlify. The contact form opens the visitor's email application; it has no server backend. Product and store details are sample content for this project.
